# کلینیک تخصصی مهر — سامانه یکپارچه مدیریت کلینیک‌های تخصصی بیمارستان

دموی کامل و کاملاً فرانت‌اند یک سامانه بیمارستانی برای مدیریت کلینیک‌های تخصصی؛ شامل شش پنل نقش‌محور، گردش‌کارهای واقعی پذیرش تا تسویه، پرونده الکترونیک، نسخه‌نویسی، صندوق و بیمه. داده‌ها همه به‌صورت ماک و فارسی هستند و هیچ بک‌اند یا پایگاه داده‌ای وجود ندارد.

- معماری: React 19 + TypeScript + Vite 6
- استایل: Tailwind CSS 3 + daisyUI 4 (تم‌های روشن و تاریک)
- آیکون‌ها: Lucide React
- فونت: Vazirmatn (بسته‌بندی‌شده با `@fontsource`؛ بدون نیاز به CDN)
- جهت‌گیری: RTL کامل، اعداد و مبالغ فارسی، تاریخ شمسی
- حالت نمایشی: کد تأیید یکبارمصرف `۱۲۳۴۵` برای همه نقش‌ها

---

## اجرای سریع

```bash
npm install
npm run dev
```

سپس آدرس خروجی Vite (به‌طور پیش‌فرض `http://localhost:5173`) را باز کنید.

```bash
npm run build     # بررسی نوع‌ها با tsc + بیلد تولیدی
npm run preview   # پیش‌نمایش بیلد
```

نیازمند Node.js 18 یا جدیدتر است. هیچ متغیر محیطی، سرور یا سرویس خارجی لازم نیست.

### اجرا در StackBlitz / CodeSandbox

کل پوشه پروژه را در سندباکس باز یا آپلود کنید و `npm install` و `npm run dev` را اجرا کنید. پروژه با Vite استاندارد است و به تنظیمات اضافه‌ای نیاز ندارد. اگر فقط فایل‌ها را کپی می‌کنید، حفظ ساختار پوشه‌های `src` مهم است.

## ورود به سامانه

۱. شماره موبایل یکی از حساب‌های نمایشی جدول زیر را وارد کنید (مثلاً ۰۹۱۲۰۰۰۰۰۰۱) و «دریافت کد تأیید» را بزنید.
۲. کد پنج‌رقمی نمایشی `۱۲۳۴۵` را وارد کنید.
۳. برای جابه‌جایی سریع بین نقش‌ها از کارت‌های «ورود سریع با حساب‌های نمایشی» در صفحه ورود یا منوی کاربر در نوار بالا استفاده کنید.

| نقش | پنل | کاربر نمایشی | شماره |
|---|---|---|---|
| مدیریت کلینیک | مدیریت و رهبری | دکتر حمیدرضا مهرابی | ۰۹۱۲۰۰۰۰۰۰۱ |
| پزشک | پزشک متخصص | دکتر سارا محمدی | ۰۹۱۲۰۰۰۰۰۰۲ |
| پذیرش و نوبت‌دهی | پذیرش و نوبت‌دهی | سمیرا احمدی | ۰۹۱۲۰۰۰۰۰۰۳ |
| پرستاری | پرستاری و خدمات سرپایی | زهرا موسوی | ۰۹۱۲۰۰۰۰۰۰۴ |
| مالی و بیمه | مالی، صندوق و بیمه‌ها | محسن رستمی | ۰۹۱۲۰۰۰۰۰۰۵ |
| بیمار | پرتال بیمار | زهرا حسینی | ۰۹۱۲۰۰۰۰۰۰۶ |

> داده‌ها در حافظه برنامه نگهداری می‌شوند و با بازخوانی صفحه به حالت اولیه برمی‌گردند. فقط تم و نشست کاربر در `localStorage` ذخیره می‌شوند (`mehr-theme` و `mehr-session`). برای بازنشانی کامل، این دو کلید را پاک کنید.

## شش پنل و قابلیت‌ها

### ۱) مدیریت و رهبری کلینیک
- داشبورد مدیریتی با KPIهای زنده: ویزیت‌ها، درآمد وصول‌شده، اشغال ظرفیت، نرخ عدم مراجعه
- نمودار روند درآمد، ترکیب بیمه‌ای مراجعین، توزیع تخصص‌ها
- مدیریت پزشکان و شیفت‌ها (ظرفیت نوبت، اتاق، تعرفه ویزیت، فعال/غیرفعال)
- گزارش‌های عملکردی با بازه‌های زمانی و خروجی نمایشی Excel/چاپ
- تعرفه‌ها و خدمات: CRUD تعرفه، درصد پوشش بیمه، سهم بیمار

### ۲) پزشک متخصص
- نوبت‌های امروز و صف بیماران با شماره صف
- پرونده الکترونیک بیمار (EHR): سابقه ویزیت‌ها، علائم حیاتی، نسخ، آزمایش‌ها و تصویربرداری
- ثبت ویزیت و شرح حال با تشخیص ICD-10، دستورات، پیگیری و ارجاع درون‌بیمارستانی
- نسخه‌نویسی الکترونیک: دارو، آزمایش، تصویربرداری، توضیحات و کد رهگیری
- مشاهده نسخ اخیر بیمار و هشدار حساسیت دارویی

### ۳) پذیرش و نوبت‌دهی
- جست‌وجو و تشکیل پرونده بیمار (بیمه پایه/تکمیلی، گروه خونی، اطلاعات هویتی)
- نوبت‌دهی حضوری، تلفنی و آنلاین با تقویم هفتگی و اسلات‌های ساعتی
- پذیرش روز و صدور قبض/فاکتور با نمایش فرانشیز بیمار
- صف انتظار هوشمند، فراخوان بیمار و نمایشگر سالن انتظار
- مدیریت لیست انتظار و شماره صف یکپارچه کلینیک در هر روز

### ۴) پرستاری و خدمات سرپایی
- تریاژ و ثبت علائم حیاتی (BMI محاسبه‌شده، فشار، اشباع اکسیژن، قند خون)
- تزریقات و پانسمان بر اساس دستور پزشک با وضعیت در انتظار/در حال انجام/انجام‌شده
- اورژانس سرپایی با سطح‌بندی تریاژ، شرح شکایت و هشدارهای ایمنی بیمار

### ۵) مالی، صندوق و بیمه
- صندوق و پرداخت‌ها: نقدی، کارت‌خوان و درگاه آنلاین
- اسناد بیمه: بیمه پایه و تکمیلی، پیش‌نویس/ارسال‌شده/پذیرفته‌شده/رد‌شده
- بستن صندوق روزانه: موجودی ابتدای روز، دریافتی به تفکیک روش پرداخت، شمارش و مغایرت‌گیری، ثبت نهایی
- گزارش درآمد، تراکنش‌های روز و وضعیت اسناد بیمه

### ۶) پرتال بیمار
- نوبت‌دهی آنلاین: انتخاب تخصص، پزشک، تاریخ و ساعت با نمایش سهم بیمه و پرداختی
- سوابق پزشکی من: ویزیت‌ها، علائم حیاتی، نسخ و مدارک
- نسخ الکترونیک من با کد رهگیری و امکان مشاهده/چاپ نسخه
- پرداخت‌ها و فاکتورها با وضعیت تسویه

## گردش‌کارهای کلیدی

### الف) پذیرش → تریاژ → فراخوان
1. پذیرش نوبت را ثبت یا بیمار را پذیرش می‌کند.
2. پرستاری علائم حیاتی و سطح تریاژ را ثبت می‌کند.
3. نوبت در صف انتظار قرار می‌گیرد و شماره صف (یکپارچه برای کل کلینیک در آن روز) نمایش داده می‌شود.
4. پذیرش با «فراخوان بعدی» بیمار را به اتاق پزشک می‌فرستد؛ نمایشگر سالن انتظار شماره جاری و نوبت‌های بعدی را نشان می‌دهد.

### ب) ویزیت → نسخه/ارجاع → پاراکلینیک
1. پزشک پرونده الکترونیک و سابقه بیمار را می‌بیند.
2. ویزیت با تشخیص ICD-10، شرح حال و دستورات ثبت می‌شود.
3. نسخه دارویی، آزمایش یا تصویربرداری صادر و کد رهگیری تولید می‌شود.
4. در صورت نیاز، ارجاع درون‌بیمارستانی با اولویت عادی/فوری ثبت می‌شود.
5. بیمار برای دریافت خدمت به پرستاری (تزریقات/پانسمان) یا پاراکلینیک هدایت می‌شود.

### ج) فرانشیز → پرداخت → بستن صندوق
1. فاکتور ویزیت بر اساس تعرفه و پوشش بیمه پایه/تکمیلی ساخته می‌شود:
   - `insuranceShare` + `supplementaryShare` + `patientShare` = مبلغ کل
2. بیمار سهم خود را نقدی، با کارت‌خوان یا درگاه آنلاین می‌پردازد.
3. اسناد بیمه پایه و تکمیلی برای ارسال به بیمه‌گر آماده می‌شوند.
4. صندوق‌دار دریافتی‌ها را با دستگاه پز مغایرت‌گیری و صندوق روز را می‌بندد.

## ساختار پروژه

```
src/
├── main.tsx                 # نقطه ورود، بارگذاری فونت و CSS
├── App.tsx                  # گیت ورود، انتخاب پنل و صفحه بر اساس نقش
├── index.css                # لایه‌های Tailwind، استایل‌های پایه و چاپ
├── types.ts                 # تایپ‌های دامنه (نقش، بیمار، نوبت، فاکتور، نسخه و…)
├── lib/
│   ├── utils.ts             # اعداد فارسی، مبلغ، تاریخ شمسی، BMI و…
│   ├── themes.ts            # فهرست تم‌های daisyUI و تم مخالف
│   └── billing.ts           # محاسبه پوشش بیمه و تقسیم فرانشیز
├── data/mock.ts             # همه داده‌های نمایشی فارسی + کاتالوگ‌ها
├── store/AppStore.tsx       # State مرکزی، نشست، تم، اکشن‌های دامنه و Toast
├── config/panels.ts         # متادیتای شش پنل و منوها
├── pages/Login.tsx          # ورود با موبایل و OTP پنج‌رقمی + ورود سریع نمایشی
├── components/
│   ├── ui/                  # Card, Badge, Avatar, StatCard, Modal, Tabs, …
│   ├── charts/              # نمودارهای SVG بدون کتابخانه خارجی
│   ├── clinic/              # اجزای مشترک دامنه (وضعیت، صف، سلول بیمار/پزشک)
│   └── layout/              # Shell، Sidebar، Topbar
└── panels/
    ├── management/          # داشبورد، پزشکان و شیفت‌ها، گزارش‌ها، تعرفه‌ها
    ├── physician/           # نوبت‌ها، EHR، ویزیت، نسخه
    ├── reception/           # بیماران، نوبت‌دهی، پذیرش، صف
    ├── nursing/             # تریاژ، تزریقات و پانسمان، اورژانس
    ├── finance/             # صندوق، اسناد بیمه، گزارش مالی و بستن صندوق
    └── patient/             # نوبت آنلاین، سوابق، نسخ، پرداخت‌ها
```

مسیریابی درون‌برنامه‌ای بدون React Router انجام می‌شود: هر پنل یک `index.ts` دارد که نگاشت `navId → Component` را صادر می‌کند و `src/panels/index.ts` این نگاشت‌ها را بر اساس نقش ترکیب می‌کند.

## طراحی و جزئیات پیاده‌سازی

- **تم‌ها:** تم پیش‌فرض `clinic` و تم تاریک اختصاصی `clinicedark`، به‌همراه تم‌های daisyUI مانند `emerald`، `corporate`، `night`، `dim` و `dracula`. انتخاب تم در نوار بالا و ذخیره در `localStorage`.
- **تاریخ:** ذخیره ISO و نمایش شمسی با `Intl.DateTimeFormat('fa-IR')`؛ امروز در داده‌های نمایشی «۱۹ آبان ۱۴۰۵» است.
- **اعداد:** همه مبالغ و شماره‌ها با ارقام فارسی و جداکننده «٬»؛ ورودی‌های عددی ارقام فارسی و لاتین را می‌پذیرند.
- **نمودارها:** SVG سبک و بدون وابستگی (`TrendChart`، `Donut`، `HBar`، `SparkBars`)؛ محورها در قالب RTL با `dir="ltr"` رندر می‌شوند.
- **پاسخ‌گویی:** چیدمان کامل برای موبایل با منوی کشویی، جدول‌های اسکرول‌پذیر و کارت‌های انعطاف‌پذیر.
- **چاپ:** استایل چاپ برای قبض و نسخه در `index.css`.
- **دسترسی:** دکمه‌ها و ورودی‌ها دارای `aria-label` یا متن قابل خواندن؛ فوکوس و کنتراست در هر دو تم رعایت شده است.
- **بدون بک‌اند:** تمام اکشن‌ها (رزرو، پذیرش، تریاژ، ویزیت، پرداخت، بستن صندوق) On-Client و با Toast تأیید می‌شوند.

### نکته‌های داده نمایشی
- ۸ پزشک در ۸ تخصص، ۱۴ بیمار، نوبت‌های امروز و ۸ ماه داده درآمد.
- شماره صف برای هر روز یکپارچه است و بر اساس ترتیب زمانی نوبت‌های همان روز تولید می‌شود.
- تعرفه میانگین ویزیت ۷۲۶٬۰۰۰ تومان با میانگین پوشش بیمه ۳۹٪ است.
- نمونه پرداختی بیمار برای ویزیت قلب: ۶۸۰٬۰۰۰ تومان با سهم بیمار ۱۰۲٬۰۰۰ تومان (پوشش ۷۰٪ پایه + ۱۵٪ تکمیلی).
